Проект: Мини-веб-магазин (HTML/JS + Supabase)
Описание проекта
Это высокоскоростной магазин на чистом стеке (HTML, CSS, Vanilla JS), использующий Supabase как бэкенд для хранения данных и GitHub/jsDelivr как CDN для картинок.

Архитектура проекта
Фронтенд: Чистый HTML5, CSS3, ES6 JavaScript.

База данных: Supabase (PostgreSQL).

Хранилище фото: GitHub (через cdn.jsdelivr.net).

Источник данных (Админка): Google Sheets (с синхронизацией в Supabase).

Инструкция по работе для Cline (Правила разработки)
1. Соблюдение чистоты кода
Ничего не удалять: Не удаляй существующие функции или блоки кода без прямой команды пользователя.

Модульность: Пиши функции, которые выполняют одну задачу (fetch данных, рендер товара, фильтрация).

Форматирование: Используй современный стандарт JS (ES6+), асинхронные функции (async/await) для работы с базой.

2. Работа с базой данных (Supabase)
Запросы: Всегда используй официальный клиент Supabase.

Структура таблицы products:

code (text), name (text), price (int4), stock (int4), color (text), size (text), type (text), image_url (text).

Безопасность: Всегда проверяй error при запросах.

3. Работа с картинками
CDN: Ссылки на фото должны генерироваться динамически через шаблон:
https://cdn.jsdelivr.net/gh/НИК/РЕПОЗИТОРИЙ@main/data/${item.code}.jpg

Оптимизация: При верстке карточки товара используй тег <img> с атрибутом loading="lazy".

4. Рендеринг интерфейса
Данные: Загрузка данных производится порциями или целиком при старте (через fetch).

DOM: Используй document.createElement или шаблонные строки для вставки товаров в контейнер.

Динамика: Если товар имеет список размеров или цветов, парси строку через .split(',') и создавай кнопки для выбора.

5. Инструкция по синхронизации (Google Sheets -> Supabase)
Если меняется структура таблицы в Google Sheets, Cline должен предложить обновить структуру таблицы в Supabase.

При необходимости написать Google Apps Script для автоматизации переноса, используй UrlFetchApp.

Чек-лист разработки (Workflow)
Создание таблицы: Убедись, что все колонки соответствуют типам данных.

Подключение: Инициализируй supabase.createClient(URL, KEY).

Логика отображения: Напиши функцию fetchProducts(), которая возвращает массив товаров.

Рендер: Реализуй функцию renderCatalog(products), которая создает HTML-карточки.

Фильтрация: Реализуй поиск по code или name и фильтр по type (трусики/лифчики).

Важные примечания для Cline
Если что-то неясно — спрашивай пользователя, не додумывай сложную архитектуру, если можно решить задачу просто.

Приоритет: Скорость загрузки сайта. Минимум лишних библиотек.

Соблюдай правило: "Пользователь — босс". Если предлагаешь изменение — объясни, почему это ускорит сайт.
